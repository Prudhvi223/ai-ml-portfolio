# Customer Churn Model Tuning

## Objective

Improve the baseline Logistic Regression model using hyperparameter tuning.

## Techniques Used

- StandardScaler
- GridSearchCV
- 5-Fold Cross Validation
- Logistic Regression

## Hyperparameters Tuned

- C: 10
- Solver: liblinear

## Evaluation

- Accuracy
- Confusion Matrix
- Classification Report

## Evaluation Summary

- Baseline Accuracy: 0.80
- Tuned Model Accuracy: 0.81
- GridSearchCV selected the best hyperparameters automatically.
- The tuned model slightly improved the baseline model's performance.
