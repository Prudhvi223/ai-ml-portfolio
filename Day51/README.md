# Day 51 — Tokenization & Text Generation

## Overview

On Day 51, I learned how text is tokenized for Large Language Models and how different sampling strategies affect text generation.

I studied Byte-Pair Encoding (BPE), temperature, Top-K sampling, Top-P sampling, and probabilistic text generation.

## Topics Covered

- Tokenization
- Byte-Pair Encoding (BPE)
- Subword tokenization
- Token IDs
- Autoregressive text generation
- Temperature
- Top-K sampling
- Top-P sampling
- Nucleus sampling
- Probabilistic sampling
