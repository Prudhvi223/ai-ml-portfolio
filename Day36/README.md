# Day 36 — Text Preprocessing

## Topics Covered

- Regex-based text cleaning
- Lowercasing
- Tokenization
- Stopword removal
- Stemming
- Lemmatization

## Hands-on Task

Built a text preprocessing pipeline using NLTK and Regex.

## Pipeline

Raw Text
→ Cleaning
→ Tokenization
→ Stopword Removal
→ Stemming / Lemmatization
→ Processed Text

## Key Learning

Stemming uses simple rules to reduce words,
while lemmatization attempts to produce meaningful
dictionary base forms.
