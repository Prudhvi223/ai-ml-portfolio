# Day 37 — Text Representation

## Objective

Learn different techniques for converting text into numerical representations for machine learning.

## Topics Covered

- Bag-of-Words
- TF-IDF
- Word Embeddings
- Word2Vec
- GloVe

## Dataset

A small toy corpus of sentences was used to demonstrate the different text representation techniques.

## Key Learnings

- Bag-of-Words represents text using word frequencies.
- TF-IDF represents the importance of words within documents.
- Word embeddings represent words as dense numerical vectors.
- Word2Vec learns representations from word context.
- GloVe uses global word co-occurrence information.

## Conclusion

Different text representation techniques provide different levels of information. Bag-of-Words and TF-IDF are simple and useful for traditional NLP tasks, while Word2Vec and GloVe provide richer semantic representations.
