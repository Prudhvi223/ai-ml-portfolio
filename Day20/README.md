# Customer Churn Streamlit App

## Objective

Create a simple web interface for the trained Customer Churn Prediction model.

## Technologies

- Python
- Streamlit
- Scikit-learn
- Joblib
- NumPy
- Pandas

## Features

- Load trained model
- Predict customer churn
- Simple Streamlit interface
- Unit tests with pytest
